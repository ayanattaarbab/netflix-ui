# Netflix UI Clone

A premium, fully responsive Netflix landing page replica engineered using pixel-perfect semantic HTML5 markup, modern CSS layouts, and adaptive multi-breakpoint media queries.

## 🚀 Features

* **Pixel-Perfect Hero Section:** Implements Netflix's iconic dynamic gradient overlay on top of high-resolution background assets, matching true brand design tokens.
* **Dynamic Trending Slider:** Horizontal scrolling carousel layout displaying the top trending titles, complete with massive custom text-shadowed index numbers.
* **"More Reasons to Join" Grid:** A modern CSS Grid component utilizing `auto-fit` and `minmax` to adjust fluidly across display architectures.
* **Micro-interactions & States:** Clean `:hover`, `:focus`, and `:active` transition feedback states across all interactive buttons, inputs, and accordion lists.
* **Comprehensive Media Breakpoints:** Fully responsive optimization catering to desktop, tablet, and ultra-narrow mobile viewports.

## 🛠️ Tech Stack

* **Structure:** HTML5 (Semantic Architecture)
* **Styling:** CSS3 (Custom Variables, Flexbox, Grid, Component Queries)
* **Typography:** Google Fonts Inter integration

## 📂 Project Structure

```text
├── assets/
│   └── svg/            # Contains all dynamic SVG UI icons
├── css/
│   └── style.css       # Core stylesheets and media queries
├── favicon.ico         # Browser tab icon
└── index.html          # Main semantic HTML markup
```
